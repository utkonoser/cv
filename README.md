# cv

Personal resume landing — terminal style, RU/EN.

Live content mirrors [LinkedIn](https://www.linkedin.com/in/nikitasgolang/). Projects: [apafit.ru](https://apafit.ru), [kk-ktokomu.ru](https://kk-ktokomu.ru).

## Local

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

Or open `index.html` directly.

## Deploy (GitHub Pages)

Repo settings → Pages → Source: Deploy from a branch → `master` / `/ (root)`.

Site URL will be `https://utkonoser.github.io/cv/` (or a custom domain if you add one).
